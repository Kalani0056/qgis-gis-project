# QGIS GIS Project

## Project Overview

This project was developed using QGIS to perform spatial analysis and identify suitable areas based on different geographic factors.

## Objectives

- Analyse geographic and spatial data
- Process building and road layers
- Calculate relevant areas
- Identify suitable areas using spatial analysis
- Produce final GIS outputs and maps

## Tools & Technologies

- QGIS
- Geographic Information Systems (GIS)
- Spatial Analysis
- Vector Data Processing
- Shapefile Data

## Key Analysis

The project includes the processing and analysis of:

- Building layers
- Road layers
- Vegetation data
- Suitable areas
- Spatial intersections and area calculations

## Project Outputs

The project contains the QGIS project file, GIS datasets, processed layers, and final analysis outputs.

## Project Files

The main QGIS project file is:

`Task_C.qgz`

The repository also contains the supporting GIS layers required for the project.
